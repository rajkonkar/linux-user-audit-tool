# 🔐 Linux User Audit Tool

This is a beginner-friendly **Linux auditing tool** designed to help cybersecurity learners and analysts quickly analyze user-related system files like `/etc/passwd`, `/etc/shadow`, and more. It supports real-time filtering, customizable searches, color-coded outputs, and a CLI-based interactive experience.

> 📁 This tool is part of my personal cybersecurity learning journey. I'm building practical tools while studying for certifications like **Google Cybersecurity Certificate**, **Security+**, and **Network+**.

---

## ⚡ Features

- 🧠 Simple, beginner-friendly CLI interface
- 🎯 Targeted file selection (choose any system file to audit)
- 🔍 Interactive search & filter options:
  - Username extraction
  - UID, GID, and shell info
  - Exclude `nologin`/`false` shell users
  - User grouping by UID range
- 🌈 Color-coded output for better readability
- 🔁 Auto-loop with return to menu
- ❌ Exit anytime with a keypress
- 🆘 Built-in help menu
