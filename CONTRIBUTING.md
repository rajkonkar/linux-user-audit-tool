# 🛠️ Contributing to Linux User Audit Tool

Thank you for your interest in contributing! This tool is built to support beginners, blue teamers, and anyone wanting to understand Linux user auditing. Let's make it better together 💙

---

## 🧠 How to Contribute

### 1. Suggest Features or Improvements
- Create an Issue and describe your idea clearly.
- Suggest UI improvements, new filters, or usability enhancements.

### 2. Report Bugs
- Open an Issue and provide:
  - Description of the bug
  - How to reproduce it
  - Screenshots (if possible)
  - System details (e.g., Kali, Ubuntu)

### 3. Submit Code
- Fork the repository
- Clone your fork
- Create a new branch (`git checkout -b feature-name`)
- Make your changes
- Submit a Pull Request (PR)

---

## 🧪 Testing Your Code

Please:
- Test your changes on Linux terminals (Kali, Ubuntu, etc.)
- Make sure you don’t modify system files — this script should remain read-only
- Validate color formatting and user output
- Keep code modular for future updates

---

## ✍️ Improving Documentation

- Fix typos or clarify confusing parts
- Add usage examples or visual help
- Enhance the README or screenshots

---

## 🙌 Thanks for Contributing!

This is a learning-based community project. All PRs, feedback, and collaborations are welcome!
